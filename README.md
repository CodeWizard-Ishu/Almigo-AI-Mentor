Almigo is built with a powerful, modern technology stack designed for reliability, speed, and intelligence.

```

│  └──────────────────────┘      └─────────────────────────┘ │

└─────────────────────────────────────────────────────────────┘
```

**Key Technologies:**

- Hugging Face - Embeddings

### How It All Works Together

```
User Types Question in Chat
        ↓
Frontend sends to Backend API
        ↓
Backend receives & validates
        ↓
AI Service processes with context
        ↓
Groq LLM generates response
        ↓
Response streams back to Frontend
        ↓
User sees answer appearing in real-time
        ↓
Conversation saved to database
        ↓
Next time, AI remembers the context
```

## 🚀 Getting Started - Set Up in 10 Minutes

### Prerequisites
- Node.js 20+ (check with `node --version`)
- PostgreSQL database running
- Redis instance
- Groq API key (free at groq.com)
- Basic command line knowledge

### Quick Start

#### 1. **Clone the Repository**
```bash
git clone <repository-url>
cd Almigo-AI-Mentor-main
```

#### 2. **Setup Backend**
```bash
cd Backend

# Install dependencies
npm install

# Create .env file with:
# DATABASE_URL=postgresql://user:password@localhost:5432/almigo
# GROQ_API_KEY=your_groq_api_key
# REDIS_URL=redis://localhost:6379
# QDRANT_URL=http://localhost:6333
# CORS_ORIGIN=http://localhost:5173
# NODE_ENV=development

# Setup database
npm run prisma:migrate

# Seed initial data
npm run seed

# Generate embeddings for search
npm run embed-mentors

# Start backend server
npm run dev
# Backend runs on http://localhost:3000
```

#### 3. **Setup Frontend**
```bash
cd ../Frontend

# Install dependencies
npm install

# Create .env file with:
# VITE_API_URL=http://localhost:3000

# Start frontend development server
npm run dev
# Frontend runs on http://localhost:5173
```

#### 4. **Open in Browser**
Visit `http://localhost:5173` and start using Almigo!
